## ASO keyword strategy

Play Store ranks on what's in your **title, short description and the
first ~167 chars of the long description**, plus install velocity and
ratings. Use these terms naturally, not stuffed:

### Tier 1 — must appear in title or short description
- hp printer
- print
- scan
- copy
- fax

### Tier 2 — must appear in first 250 chars of full description
- mobile printing
- wireless / Wi-Fi
- photo print / document print
- HP Smart (matches the official HP app name; your app is positioned as a
  lighter alternative, not a clone)

### Tier 3 — sprinkle naturally throughout the long description
- wifi printer, printer app, print from phone, scan to pdf, document
  scanner, photo printer, id card copy, mobile fax, hp deskjet,
  hp officejet, hp envy, hp laserjet, mopria, wi-fi direct,
  print service plugin, printer setup, ink levels

### Avoid
- Brand-name claims you can't back ("official HP app"): grounds for
  removal.
- Excessive punctuation in the title (e.g. "Print!! HP!!"): rejected
  by Play Console policy.
- Repeating the same keyword > ~5 times in one description: looks spammy
  and trips Play's metadata heuristics.
